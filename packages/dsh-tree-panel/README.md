# dsh-tree-panel

把 DeepSeek Harness 的**会话历史画成一棵分支树**：一个卡片 = 一轮对话，分支从它分叉的那一轮长出来，点卡片直接跳到对应会话的那一轮。

## 功能

- 会话按 `parentId` 折成合并图，共享历史只画一次。
- 轮次级卡片（最后一条用户消息 + 该轮回复摘要），点卡片定位到该轮。
- 从任意轮次开新分支（记录 fork 锚点），星标/归档/按工作区筛选。
- 右键菜单：分叉、打开、复制会话 id。
- 列表视图（虚拟化）+ 画布视图（缩放/平移）；右下角缩略图，点哪里跳哪里。
- 卸载时还原对 `sessions.fork` 的包装，不把宿主留在被改写的状态。

## 安装

```bash
dsh plugin --profile web add <包名或本地路径>
```

装完重启 DSH。纯 Client 插件，无 Host 依赖、无配置。

## 兼容性

针对 DSH 0.2.x 的客户端槽位 API（`sidebar.panellist` / `main`）。宿主升级后如侧边栏按钮消失，先看控制台是否有槽位注册错误。

## 已知边界

- 父子指针成环（导入/手改会话头导致）会被提回根层；极深链有 4096 层兜底。
- 画布视图与列表视图共用同一份图数据，缩放只影响呈现。
